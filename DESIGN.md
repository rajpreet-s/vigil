# Vigil Design Specifications

Vigil is split into two visual packages, each with its own dedicated design guidelines and technical parameters. Please refer to the specific package directory for its corresponding `DESIGN.md`:

1. **Vigil Landing Page & Marketing Site (`packages/web`)**
   - Location: [packages/web/DESIGN.md](file:///Users/raj/VSCode/vigil/packages/web/DESIGN.md)
   - Scope: Hero sections, brand identity, Space Grotesk/Inter token definitions, ambient radial glows, and the signature "storm-to-correlated" alert loops.

2. **Vigil SRE Incident Command Dashboard (`packages/app`)**
   - Location: [packages/app/DESIGN.md](file:///Users/raj/VSCode/vigil/packages/app/DESIGN.md)
   - Scope: Product thinking (triaging vs. evaluating journeys), Settle-timer storm animations, dense SRE UX layouts, interactive LangGraph execution traces, Prometheus query log consoles, and the Agent Evaluation dashboard.
